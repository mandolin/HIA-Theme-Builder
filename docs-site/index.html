HIA-Theme-Builder 文档

主题构建器 · 从取色到配色体系再到多端产出的完整工作流。当前版本 v0.2.x，文档随 v0.3 持续完善（英文版排期中）。

🚀 入门教程

5 分钟上手：选一个主色 → 生成配色 → 应用到预览 → 导出 Token。第一次使用从这里开始。

📘 使用手册

全功能讲解：操作台、配色关系与辅助色、配色宝典、渐变、主题市场、取色探索、预览区。

🛠 参考及开发文档

core API、主题模型契约（ADR-007）、Token 结构、导出适配器、桌面端架构与二次开发指南。

入口说明
在线版无需安装，浏览器直接使用全部主题能力（取色探索需桌面端）。
桌面版下载Electron / Tauri 双实现，Windows 便携版与安装器，附 SHA-256 校验。
源码仓库MIT/Apache-2.0 开源，mono-repo：core 公共核心 + web/electron/tauri 三端。
浏览器在线版与桌面端的界面完全一致（共享同一渲染器）；仅"网址取色探索"能力为桌面端专属（需要真实渲染环境与 SSRF 防护）。
