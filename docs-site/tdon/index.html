TDON 声明式主题适配规范Declarative Theme-Adapter Spec

当前版本 tdon-0.2。一个 TDON 文件描述"某个目标长什么样、导出哪些文件"，由 Theme Builder 解释执行——不携带可执行代码。npm 包 @hia/tdon，零第三方依赖。 Current version tdon-0.2. One TDON file declares what a target looks like and which files it exports, interpreted by Theme Builder — no executable code. npm package @hia/tdon, zero third-party dependencies.

30 秒了解In 30 seconds

{
  "specVersion": "tdon-0.2",
  "target": { "id": "my-docs", "name": "我的文档站" },
  "preview": {
    "layout": "stack",
    "nodes": [
      { "type": "hero", "title": "主视觉", "bgToken": "gradient:carousel" },
      { "type": "card", "title": "卡片刻", "text": "正文", "bgToken": "primary.50" }
    ]
  },
  "exportManifest": {
    "files": [
      { "path": "theme/custom.css", "template": ":root { --brand: {{token:primary.500}}; }" }
    ]
  }
}

颜色全部来自 令牌引用（primary.500、gradient:carousel），不写死色值；导出的 CSS 里插值会替换成当前主题的真实色值。 Every color comes from a token reference (primary.500, gradient:carousel) — no hardcoded values. Interpolations in exported CSS resolve to the current theme's real colors.

在代码里使用Use it in code

npm install @hia/tdon
import { parseTdonDocument, renderTdonPreview, createTdonExportTarget } from '@hia/tdon';

const { result, doc } = parseTdonDocument(raw, { theme });
if (!result.ok) {
  // 每条含 code / path / message（中英双语）
  console.error(result.errors);
} else {
  const html  = renderTdonPreview(doc, theme);           // 预览 HTML 片段
  const files = createTdonExportTarget(doc).files(theme); // [{ path, content }]
}
设计边界Design boundary
TDON 只读、纯声明。需要条件逻辑/循环/变量时走预留的 TDOT（template 段），当前接受但暂不生效。 TDON is read-only and purely declarative. For conditionals/loops/variables use the reserved TDOT block (template), accepted today but inert.
