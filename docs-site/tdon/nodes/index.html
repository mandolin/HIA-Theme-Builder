9 类预览节点的属性与语义。所有节点可带通用字段 id、effect、children。Attributes and semantics for the nine preview node types. Every node may carry the shared fields id, effect and children.

渲染安全Rendering safety
所有文本渲染前 HTML 转义；节点上不允许出现任意 CSS 字符串；图片一律懒加载且不发送 referrer。 All text is HTML-escaped before rendering; no arbitrary CSS strings are allowed on nodes; images are always lazy-loaded with no referrer.
