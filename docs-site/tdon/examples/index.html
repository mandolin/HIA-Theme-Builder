示例文件Example Files

全部示例随 @hia/tdon 分发（tdon-examples/），并有集成测试在默认主题下复核——新建主题后直接连接即可用。All examples ship with @hia/tdon (tdon-examples/) and are covered by tests against a default theme — connect one right after creating a theme and it works.

怎么用How to use

在 Theme Builder 里：预览区切到「自定义支持」→ 来源下拉三选一：URL 源（粘贴地址）/ 本地文件（选文件）/ 内置示例（再选「后台仪表盘示例」或「编辑器主题示例」）→ 点「连接 TDON」。In Theme Builder: switch the preview to "Custom Support" → pick one of three sources: URL (paste an address) / Local file / Built-in example (then choose "Dashboard example" or "Editor-theme example") → click "Connect TDON".

内置示例与下方 URL 旗舰示例内容刻意不重叠：前者展示后台仪表盘与编辑器四格式主题，后者展示 VitePress 多页文档站——两个入口对应不同目标形态。The built-in examples deliberately do not overlap with the URL flagship below: the former show a dashboard and editor-theme formats, the latter a multi-page VitePress docs site — different target shapes for different entries.

本目录文件由 Pages 工作流直接从 HIA/tdon/tdon-examples/ 拷贝发布（应用内置示例同源）——包更新即自动重发布，不会出现「官网版本落后」。 Files in this directory are published by the Pages workflow straight from HIA/tdon/tdon-examples/ (the same source as the app's built-in examples) — package updates republish automatically, so the site never lags behind. 
npm install @hia/tdon
import { parseTdonDocument, renderTdonPreview, createTdonExportTarget } from '@hia/tdon';
import { readFileSync } from 'node:fs';

const raw = JSON.parse(readFileSync('tdon-examples/vitepress-docs.tdon.json', 'utf8'));
const { result, doc } = parseTdonDocument(raw, { theme });
if (!result.ok) console.error(result.errors);
if (doc) {
  const html  = renderTdonPreview(doc, theme);
  const files = createTdonExportTarget(doc).files(theme);
}

  "target": {
    "id": "minimal-theme",
    "name": "最小示例",

  "exportManifest": {
    "files": [
      {
        "path": "tokens.css",
        "template": ":root {\n  --brand: {{token:primary.500}};\n}\n"
      }
    ]
  }
}
