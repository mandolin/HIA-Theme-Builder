示例文件Example Files

全部示例随 @hia/tdon 分发（tdon-examples/），并有集成测试在默认主题下复核——新建主题后直接连接即可用。All examples ship with @hia/tdon (tdon-examples/) and are covered by tests against a default theme — connect one right after creating a theme and it works.

怎么用How to use

在 Theme Builder 里：预览区切到「自定义支持」→ 选「URL 源」或「本地文件」→ 连接；或直接点「加载示例」。In Theme Builder: switch the preview to "Custom Support" → choose a URL or local file → connect; or click "Load example" directly.

npm install @hia/tdon
import { parseTdonDocument, renderTdonPreview, createTdonExportTarget } from '@hia/tdon';
import { readFileSync } from 'node:fs';

const raw = JSON.parse(readFileSync('tdon-examples/vitepress-docs.tdon.json', 'utf8'));
const { result, doc } = parseTdonDocument(raw, { theme });
if (!result.ok) console.error(result.errors);
if (doc) {
  const html  = renderTdonPreview(doc, theme);
  const files = createTdonExportTarget(doc).files(theme);
}

最小示例全文The minimal example, in full

{
  "specVersion": "tdon-0.2",
  "target": {
    "id": "minimal-theme",
    "name": "最小示例",
    "nameEn": "Minimal Example"
  },
  "exportManifest": {
    "files": [
      {
        "path": "tokens.css",
        "template": ":root {\n  --brand: {{token:primary.500}};\n}\n"
      }
    ]
  }
}
