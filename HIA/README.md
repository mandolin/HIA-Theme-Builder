# HIA 子体系入口

本目录存放 HIA-Theme-Builder 的各子体系/包，均位于公开主库内但独立演进。

| 子目录 | 角色 | 仓库边界 |
| --- | --- | --- |
| `core/` | 公共核心：主题模型、配色算法、Token 导出、预览组件。 | 主库公开，可被其他端引用 |
| `web/` | 网页版，部署 GitHub Pages。 | 主库公开 |
| `electron/` | Electron 桌面版，含网址取色等能力。 | 主库公开 |
| `tauri/` | Tauri 桌面版，含网址取色等能力。 | 主库公开 |

各子体系的具体规划（`G-*`）、里程碑与任务状态保存在私有 `work-zone/`。
